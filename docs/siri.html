🗣️ دستیار صوتی «Ancient idea»

با گفتن «Hey Siri, Ancient idea» آیفون عنوان و هوک شورتِ امروز را می‌خواند، روی صفحه نشان می‌دهد و صفحهٔ کارخانه را باز می‌کند. یک بار ساختنش حدود ۵ دقیقه طول می‌کشد.
⬅️ بازگشت به شورت امروز

⚠️ نکتهٔ مهم دربارهٔ «ایده امروز»

سیری زبان فارسی را پشتیبانی نمی‌کند، پس جملهٔ صوتی فارسی «ایده امروز» را نمی‌فهمد. راه‌حل: فرمان صوتی انگلیسی Ancient idea را بساز، و برای فارسی یک کپی با نام «ایده امروز» بساز که با دکمهٔ Action آیفون ۱۶ پرو مکس، آیکون روی صفحهٔ اصلی یا ویجت اجرا شود (مرحلهٔ ۱۲ تا ۱۴).

🛠️ ساخت شورتکات (منوی آیفون انگلیسی)

۱
برنامهٔ Shortcuts را باز کن، تب Shortcuts ← دکمهٔ + بالا سمت راست.
۲
بالای صفحه روی اسم شورتکات بزن ← Rename ← بنویس Ancient idea (همین اسم، فرمان سیری است).
۳
روی Add Action بزن، در جست‌وجو بنویس URL و اکشن URL را اضافه کن. در آن این آدرس را بگذار: https://ghasemiarash813.github.io/am-short-factory/today.json
۴
اکشن Get Contents of URL را اضافه کن (تنظیماتش را دست نزن؛ Method همان GET).
۵
اکشن Get Dictionary from Input را اضافه کن.
۶
اکشن Get Dictionary Value را اضافه کن. روی Key بزن و بنویس short.title . مطمئن شو جملهٔ آن این است: Get Value for short.title in Dictionary.
۷
یک Get Dictionary Value دیگر اضافه کن. Key را بنویس short.hook . روی کلمهٔ آبی آخر (Dictionary Value) بزن ← Select Variable ← خروجی مرحلهٔ ۵ یعنی Dictionary را انتخاب کن.
۸
اکشن Text را اضافه کن و داخلش بنویس: Today's Short: [عنوان]. Hook: [هوک] به‌جای [عنوان] از نوار بالای کیبورد متغیر Dictionary Value مرحلهٔ ۶ را بگذار و به‌جای [هوک] متغیر Dictionary Value مرحلهٔ ۷ را (برای اطمینان: روی متغیر بزن ← Select Variable).
۹
اکشن Speak Text را اضافه کن (ورودی‌اش خودکار Text است). با فلش کوچک ‹ آن، Language را English (US) بگذار.
۱۰
اکشن Show Result را اضافه کن و ورودی‌اش را متغیر Text (مرحلهٔ ۸) بگذار.
۱۱
اکشن Open URLs را اضافه کن و آدرس را بنویس: https://ghasemiarash813.github.io/am-short-factory/ سپس Done. حالا بگو: «Hey Siri, Ancient idea» ✅

🇮🇷 نسخهٔ فارسی «ایده امروز» (بدون صدا)

۱۲
روی شورتکات Ancient idea انگشت را نگه دار ← Duplicate ← نسخهٔ جدید را Rename کن به ایده امروز.
۱۳
دکمهٔ Action: Settings ← Action Button ← بکش تا Shortcut ← Choose a Shortcut ← «ایده امروز». حالا با نگه داشتن دکمهٔ کنار گوشی اجرا می‌شود.
۱۴
آیکون صفحهٔ اصلی: داخل شورتکات، دکمهٔ ⓘ یا منوی اشتراک پایین ← Add to Home Screen ← Add.

🧩 اگر کار نکرد

• اگر سیری گفت «there's a problem»: یک بار شورتکات را دستی اجرا کن و به Allow برای دسترسی به سایت جواب بده.
• روزهایی که خبر تازه نبوده یا ساخت خطا داده، عنوان خالی است؛ صفحه باز می‌شود و پیام را نشان می‌دهد.
• برای اینکه سیری فارسی بخواند لازم نیست؛ عنوان شورت انگلیسی است.
